# Imbir Keeper

Корпоративный мессенджер с задачами: чаты отделов, лента обновлений Daily, задачи с исполнителями и календарём, уведомления, профиль. Вёрстка по видео-референсу, работает как мобильное приложение (iOS-навигация, шторки, свайпы) и как настольное ПО (боковая панель, разделённые панели, Ctrl+K).

Бэкенда пока нет — всё работает на мок-сервере в браузере (данные в `localStorage`).

Демо: https://seitek2002.github.io/imbir-crm/

## Запуск

```bash
npm install
npm run dev        # http://localhost:5180
```

Вход: любой демо-сотрудник, пароль `123456` (по умолчанию подставлен `aiperi@imbir.example`).

| Скрипт | Что делает |
| --- | --- |
| `npm run build` | проверка типов + сборка |
| `npm run lint` | ESLint |
| `npm run lint:fsd` | steiger — проверка правил FSD |
| `npm run format` | Prettier |

Pre-commit (husky + lint-staged) форматирует изменённые файлы.

## Публикация демо

```bash
npm run deploy
```

Команда собирает сайт и пушит его в ветку `gh-pages` этого репозитория, откуда его отдаёт GitHub Pages.

Всё, что попадает в сборку, видно всем, включая демо-данные из `src/shared/api/mock/seed.ts`. Не кладите туда настоящие имена, переписку, ключи и пароли.

## Стек

React 19 + TypeScript, Vite, Tailwind CSS v4, zustand (клиентское состояние), TanStack Query (серверное), react-router.

## Архитектура — Feature-Sliced Design

```
src/
  app/        точка входа, роутинг, переходы между экранами, глобальные стили
  pages/      экраны (страница + её собственные части)
  widgets/    app-shell: таб-бар, боковая панель, раскладка «список + детали»
  features/   действия, нужные в нескольких местах: фильтры и форма задач,
              поиск/палитра, настройки, блокировка, realtime-мост
  entities/   chat, message, task, user, notification, session — запросы и UI сущностей
  shared/     api (клиент + мок-сервер), ui-кит, lib (i18n, форматирование, хуки), model, config
```

## Мок-бэкенд

`src/shared/api/mock` — «сервер» с REST-маршрутами (`/chats`, `/tasks`, `/me`, …), задержкой сети, кодами ошибок и событиями «websocket» (`realtime.ts`). Коллеги «живые»: отвечают в личке, читают сообщения, иногда пишут сами и двигают задачи.

Чтобы подключить настоящий бэкенд, замените тело `transport` в `src/shared/api/client.ts` на `fetch`/axios — контракт описан в `src/shared/api/types.ts`. Realtime-события принимает `src/features/realtime-bridge`.

Сбросить демо-данные: Профиль → О приложении → «Сбросить демо-данные».
